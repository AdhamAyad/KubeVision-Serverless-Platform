# KubeVision-Serverless-Platform
A high-performance, event-driven AI inference platform built on AWS/EKS with Terraform. Featuring serverless auto-scaling (Scale-to-Zero) via Knative &amp; KServe, GitOps-driven delivery with ArgoCD, and automated CI/CD via in-cluster GitHub Action Runners. Fully monitored with Prometheus &amp; Grafana for end-to-end Observability.
